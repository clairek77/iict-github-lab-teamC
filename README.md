# 🔮 수상한 타로 가게  
2025-2 정보문화기술입문 수업 과제 프로젝트

---

## 📌 프로젝트 소개
**수상한 타로 가게**는 2026년 ‘붉은 말의 해’를 맞아, 20대 사용자의 개인적인 고민과 동시대 청년 이슈를 함께 비추는 **맞춤형 생성 타로 카드 경험**을 제공하는 인터랙티브 웹 프로젝트입니다.

기존의 ‘카드를 뽑는’ 타로 방식이 아니라, 사용자의 선택과 입력을 바탕으로 **카드를 생성**함으로써  개인적인 운세 해석을 넘어 사회적 맥락과 실질적인 정보까지 연결하는 것을 목표로 합니다.

---

## 📌 기획 의도

###  2026 신년맞이 시즈널 기획
- 2026년 ‘붉은 말의 해’를 테마로 한 신년 타로 경험
- 새로운 한 해를 앞둔 20대의 불안과 기대에 주목

### 생성형 타로 카드
- 이미 정해진 카드를 ‘뽑는’ 방식이 아닌  **개인의 고민에 맞춰 생성되는 타로 카드**
- 사용자 선택에 따라 텍스트와 이미지가 달라지는 구조

### 개인의 고민에서 사회적 이슈로 확장
- 20대 개인의 사적인 고민에 머무르지 않고  
  또래 청년들이 공통적으로 겪는 **사회적 문제**를 함께 제시
- 추상적인 조언에 그치지 않고 **청년 정책·지원 정보 등 외부 링크**로 연결하여 실제 도움 제공으로 이어질 수 있도록 설계

---

## 🃏 카드 구성

사용자는 총 **세 장의 카드**를 만나게 됩니다.

1. **생성 타로 카드**  
   - 개인적인 고민을 바탕으로 생성되는 내년의 운세 카드

2. **흐름 카드**  
   - 해당 고민과 관련해  또래 청년들이 함께 겪는 사회적·구조적 문제를 보여주는 카드

3. **조언 카드**  
   - 문제 해결에 도움이 될 수 있는  청년 지원 정보, 정책, 외부 링크를 제시하는 카드

---

## 🕹️ 사용 방법

1. 입장
2. 프로젝트 소개 화면
3. 고민 카테고리 선택
4. 세부 카테고리 선택
5. 수정구슬 인터랙션을 통한 랜덤 키워드 결정
6. 카드 뽑기 인터랙션을 통한 첫 번째 카드 확인
7. 카드 뽑기 인터랙션을 통한 두 번째 카드 확인
8. 카드 뽑기 인터랙션을 통한 세 번째 카드 확인
9. 결과 요약 QR 코드 제공

## ⚙️ 기술적 요구사항

- 본 프로젝트는 **Gemini API Key**를 사용합니다. 타로 카드 생성 직전의 화면에 뜨는 입력란에 API Key를 입력해 주세요.
- PC 환경에서의 사용을 권장합니다.
- 화면은 CSS로 자동 스케일링되지만, 노트북 환경에서는 필요 시 알맞게 브라우저 창 크기를 조정하는 것을 권장합니다.
